# 产品需求文档 (PRD)
# 「灵感笔」— AI 社媒内容创作助手

> 版本：v1.0 | 日期：2026-06-11 | 状态：待确认

---

## 一、产品定位

**一句话描述**：面向中国自媒体创作者的 AI 内容创作工具，能一键生成符合小红书/抖音/公众号/B站/微博/快手等各大平台独特风格的爆款内容。

**核心价值主张**：
> "通用 AI 写出来的东西没平台味，灵感笔让 AI 懂每个平台的调性。"

**产品名称**：灵感笔（LingganPen）| 英文：ContentSpark

---

## 二、目标用户

### 主要用户画像

| 画像 | 描述 | 付费能力 |
|------|------|----------|
| **个人自媒体创作者** | 同时运营 2-3 个平台，日均发文 1-3 篇，希望提效 | ¥20-50/月 |
| **兼职副业创作者** | 有本职工作，利用业余时间做自媒体赚副业收入 | ¥10-30/月 |
| **小微电商卖家** | 需要在小红书/抖音等平台发布种草内容引流 | ¥20-50/月 |
| **MCN / 内容团队** | 管理多个账号，需要标准化内容产出流程 | ¥100-300/月 |

### 用户核心痛点

1. **平台风格不对味**：ChatGPT/文心一言生成的内容"AI味太重"，不符合各平台调性
2. **多平台改写耗时**：同一主题要为每个平台分别写一遍，费时费力
3. **选题困难**：不知道今天写什么，缺乏灵感
4. **标题吸引力不够**：内容质量不差但标题导致点击率低
5. **标签/话题不精准**：不懂得利用热门话题和 SEO 关键词

## 三、MVP 功能范围

### P0 — 核心功能（MVP 必须交付）

#### 1. 平台风格引擎
- 预设 6 大平台风格模板（小红书/抖音/公众号/B站/微博/快手）
- 每个平台包含：语气、排版、emoji 密度、标题套路、字数范围等完整风格参数
- 用户选择平台后自动切换对应的 Prompt 模板

#### 2. 一键内容生成
- 用户输入：主题关键词 + 内容类型 + 平台选择
- AI 输出：
  - 3 个标题变体供选择
  - 完整正文内容（符合平台风格）
  - 推荐 5-10 个标签/话题
  - 封面文字建议
  - 发布时间建议

#### 3. 多平台改写
- 输入一段已有内容，选择目标平台
- AI 自动改写为符合目标平台风格的版本
- 保持核心信息不变，调整语气/排版/字数

#### 4. 选题灵感器
- 用户选择创作领域（美妆/美食/科技/教育/穿搭/健身/旅行等 15+ 品类）
- AI 生成 5-10 个选题建议，附推荐理由和预估热度

#### 5. 标题优化器
- 输入草稿标题 → 生成 5 个优化版本
- 按平台套路分类展示（悬念型/数字型/痛点型/对比型等）

### P1 — 增值功能（MVP 后迭代）

| 功能 | 描述 |
|------|------|
| 视频脚本生成 | 分镜 + 口播词 + BGM 建议 + 字幕文案 |
| 标题 A/B 测试 | 生成多版本标题 + 预估点击率评级 |
| 历史记录 | 保存生成历史，支持二次编辑 |
| 创作者风格学习 | 上传历史作品，学习用户个人写作风格 |
| 内容日历 | 策划排期 + 发布提醒 |

### P2 — 远期功能

| 功能 | 描述 |
|------|------|
| 热点追踪 | 接入各平台热搜，自动关联用户领域 |
| 标签算法优化 | 基于各平台推荐算法推荐最优标签组合 |
| 团队协作 | 多人共享模板、审核流程 |
| API 开放 | 提供第三方集成接口 |

## 四、技术方案

### 4.1 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| **前端框架** | Flutter 3.x + Dart | 跨平台 iOS / Android / Web |
| **状态管理** | Riverpod | 轻量、可测试 |
| **AI 引擎** | GLM API (主力) | 中文内容生成质量高、成本可控 |
| **后端服务** | Supabase | 用户系统 + 数据存储 + Edge Functions |
| **本地存储** | Hive | 生成历史、用户设置离线缓存 |
| **支付** | Apple IAP + 支付宝/微信 | 应用内购 + 国内支付 |
| **云端构建** | Codemagic | M 系列 Mac 云端编译 iOS |
| **版本控制** | Git + GitHub | 代码托管 + 触发云端构建 |

### 4.3 Prompt 模板架构

```dart
class PlatformStyle {
  final String name;           // "小红书"
  final String systemPrompt;   // 角色定义 + 平台风格规则
  final int titleMin;          // 标题字数下限
  final int titleMax;          // 标题字数上限
  final int contentMin;        // 正文字数下限
  final int contentMax;        // 正文字数上限
  final String emojiDensity;   // "high" / "medium" / "low" / "none"
  final List<String> titlePatterns;  // 标题套路列表
  final List<String> forbidden;      // 禁忌项
  final List<String> mustHave;       // 必含元素
}
```

### 5.2 核心交互流程

```
用户打开 App
  → 首页展示创作工作台
  → 选择目标平台（如"小红书"）
  → 选择内容类型（如"种草笔记"）
  → 输入主题关键词（如"夏日防晒霜推荐"）
  → 点击「生成内容」
  → 等待 3-8 秒
  → 展示结果：
    ├── 📌 标题选择（3 个变体，点击切换）
    ├── 📝 正文内容（可编辑）
    ├── 🏷️ 推荐标签（一键复制）
    ├── 🖼️ 封面文字建议
    └── ⏰ 发布时间建议
  → 用户可一键复制全文 / 单独复制某部分 / 重新生成
```

## 八、风险与应对

| 风险 | 概率 | 影响 | 应对策略 |
|------|------|------|----------|
| AI 生成内容质量不稳定 | 高 | 高 | 持续迭代 Prompt 模板，增加人工审核机制 |
| GLM API 不可用/涨价 | 中 | 高 | 设计模型抽象层，可切换至 DeepSeek/Qwen 备用 |
| 用户不愿付费 | 中 | 高 | 免费版提供足够价值，付费版功能差异化明显 |
| 苹果审核被拒 | 中 | 中 | 避免敏感内容生成，完善内容审核机制 |
| 竞品跟进 | 低 | 中 | 深耕平台风格模板库，建立内容壁垒 |

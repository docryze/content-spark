# 产品需求文档 (PRD)
# 「灵感笔」ContentSpark — AI 社媒内容创作助手

> 版本：v2.0 | 日期：2026-06-11 | 状态：确认

---

## 一、产品定位

**一句话**：面向中国自媒体创作者的 AI 内容创作工具，让 AI 真正懂每个平台的调性，一次创作、多平台自动适配。

**核心差异化（V2 新增）**：
1. 🔄 **跨平台自动改编** — 一篇内容 → 6 大平台自动适配
2. 🧹 **AI 去 AI 味** — 检测 AI 痕迹，改写为真人风格
3. 🔥 **热点追踪 + 一键生成** — 实时热搜推送，一键蹭热点

---

## 二、目标用户

| 画像 | 描述 | 付费能力 |
|------|------|----------|
| **个人自媒体创作者** | 运营 2-3 个平台，日均发文 1-3 篇 | ¥20-50/月 |
| **兼职副业创作者** | 本职工作外做自媒体赚副业收入 | ¥10-30/月 |
| **小微电商卖家** | 需在多平台发布种草内容引流 | ¥20-50/月 |
| **MCN / 内容团队** | 管理多账号，需要标准化产出 | ¥100-300/月 |

### 核心痛点（用户调研 Top 5）

1. **AI 味太重**（78% 投诉）— 被平台检测限流
2. **多平台改写耗时**（72%）— 同一主题每个平台写一遍
3. **同质化严重**（65%）— 多人生成雷同内容
4. **不懂平台调性**（58%）— 内容风格不匹配
5. **热点响应慢**（48%）— 热点来了来不及跟进

### V2 新增功能 🔥

#### P0 — 核心

##### 1. 跨平台内容自动改编
- **入口**：首页新增「一键改编」模式
- **输入**：用户粘贴一段已有内容（任意来源）
- **输出**：自动识别来源平台 → 生成其他 5 个平台的适配版本
- **交互**：
  - 选择源平台 → 粘贴原文
  - 选择目标平台（可多选，如选"抖音+公众号+微博"）
  - 点击「开始改编」→ 流式生成各平台版本
  - Tab 切换查看各平台结果，各自独立复制
- **技术**：Prompt 注入源平台特征 + 目标平台风格参数，保持核心信息不变

##### 2. AI 去 AI 味（人性化改写）
- **入口**：首页新增「去 AI 味」模式 + 生成结果页的「优化」按钮
- **检测**：
  - 用 GLM 分析文本中的 AI 痕迹（过度正式、重复结构、万能句式、缺乏个人观点）
  - 标注可疑段落，给出「AI 味指数」（0-100%）
- **改写**：
  - 一键人性化改写：替换空洞表达、加入口语化/个人观点、调整句式节奏
  - 改写前后对比展示（左右或上下分栏）
- **技术**：两段式 Prompt — 先检测评分，再针对性改写

##### 3. 热点实时追踪 + 一键生成
- **入口**：首页新增「🔥 热点」Tab / 浮动按钮
- **数据源**：
  - 微博热搜（免费 API / 爬虫）
  - 百度热搜
  - 知乎热榜
  - 抖音热榜
- **功能**：
  - 实时展示各平台热搜 Top 20
  - 按用户创作领域自动筛选相关热点
  - 点击热点 → 自动生成选题建议
  - 一键生成对应平台的内容
- **刷新**：每 30 分钟自动更新，支持下拉刷新

### 4.2 交互设计要点

- **模式切换**：首页顶部 3 个胶囊 Tab（创作/改编/去AI味），左右滑动切换
- **改编结果**：横向 Tab 切换各平台版本，每个版本独立预览卡片
- **去AI味评分**：圆形进度条 + 颜色变化（绿→黄→红），段落高亮标注
- **热点卡片**：排名 + 热度值 + 关联领域标签 + 一键生成按钮
- **底部导航**：创作 / 热点 / 历史 / 我的（4 个 Tab）

## 七、技术方案（V2 新增）

### 7.1 跨平台改编引擎

```
用户粘贴原文 → 自动识别源平台
                    ↓
        Prompt: "将以下[源平台]风格的内容改写为[目标平台]风格"
        注入：源平台特征 + 目标平台风格参数 + 保持核心信息不变的约束
                    ↓
        流式生成目标平台版本 × N（多选目标时并行请求）
```

### 7.2 去 AI 味引擎

```
用户粘贴文本 → GLM 检测 Prompt
                    ↓
        输出：AI味评分(0-100) + 可疑段落标注 + 原因
                    ↓
        用户点击「人性化改写」
                    ↓
        GLM 改写 Prompt: "将以下AI味段改写为真人创作风格"
        注入：具体修改建议 + 口语化/个性化/观点化约束
                    ↓
        流式输出改写后文本 + 前后对比展示
```

### 7.3 热点追踪

```
定时任务(30min) → 爬取热搜 API
                    ↓
        微博热搜 / 百度热搜 / 知乎热榜 / 抖音热榜
                    ↓
        存储到本地 + 按用户领域匹配相关性
                    ↓
        首页热点入口 → 热点列表 → 一键生成
```
